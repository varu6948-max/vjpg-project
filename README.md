# VJ-PGs (vjpg.vercel.app)

```
frontend/   static site (Vercel)  - same design, images, logo and fonts as vjpgs.vercel.app
backend/    Node/Express API (Render) - signup/login stored in Excel, coupon PDF + email
render.yaml Render blueprint
```

## What was added vs. the original site
The original had no accounts: its booking form emailed the team through formsubmit.co and filled a `token_template.pdf` (that file wasn't in the zip, so the PDF is now generated by the backend with the same fields).

| Feature | How it works |
|---|---|
| Sign up / Log in | `POST /api/signup`, `POST /api/login`. Stored in **`vjpgs-data.xlsx`** (sheet `Users`). Passwords are saved as bcrypt hashes, never plain text. |
| Confirm Discount | Requires login. The server checks the price, creates the token, appends it to sheet `Coupons`, builds the PDF and returns it. |
| Download for the user | The browser saves `VJ_Token_<id>.pdf` automatically (plus a "Download again" button). |
| Auto-email | The same PDF is emailed to **varungowdaj77@gmail.com** via Resend. The send result is logged in the `Coupons` sheet. |

## Deploy

### 1. Backend on Render
1. Push this folder to a GitHub repo.
2. Render dashboard -> **New -> Blueprint** -> pick the repo (uses `render.yaml`).
3. When prompted, set `RESEND_API_KEY` (from resend.com -> API Keys).
4. After it deploys, note the URL (default `https://vjpg-api.onrender.com`). If it differs, edit `frontend/js/config.js` (`API_BASE`).

Excel persistence: Render's normal filesystem is wiped on every restart/deploy. The blueprint therefore attaches a persistent disk, which needs the **Starter** plan or above. On the free plan, remove the `disk:` block and `DATA_DIR`; the app still works, but the Excel file resets on redeploys, so download it regularly: `curl -H "x-admin-key: <ADMIN_KEY>" https://<api>/api/admin/export -o vjpgs-data.xlsx`.

### 2. Frontend on Vercel
1. Vercel -> **Add New Project** -> same repo -> **Root Directory: `frontend`** -> Framework: *Other* -> name the project **`vjpg`** (gives `vjpg.vercel.app`, if the name is free).
2. Deploy. No build step is needed.

### Email sender note
Without a verified domain, Resend only lets the sender `onboarding@resend.dev` deliver to the email address that owns the Resend account. Either sign up for Resend with `varungowdaj77@gmail.com`, or verify a domain in Resend and set `MAIL_FROM` (for example `VJ-PGs <noreply@yourdomain.com>`) on the Render service.

## Run locally
```
cd backend && npm install && npm start     # http://localhost:4000
cd frontend && python3 -m http.server 3000 # http://localhost:3000
cd backend && npm test                      # end-to-end API test
```
